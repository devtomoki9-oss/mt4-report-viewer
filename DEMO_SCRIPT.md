# Demo Video Script — MT4 Report Viewer Pro

**Target:** Lemon Squeezy marketplace application
**Duration:** 2–3 minutes
**Resolution:** 1920×1080, 60fps recommended
**Language:** English (for global audience)

---

## Pre-recording Checklist

- [ ] Open browser in a clean profile (no personal bookmarks visible)
- [ ] Set browser zoom to 100%
- [ ] Open the app at the production URL
- [ ] Download the 3 demo JSON files from `/demo/` folder:
  - `ScalpBot_Pro.json`
  - `TrendEA_GBPUSD.json`
  - `ManualTrader_JPY.json`
- [ ] Hide the browser toolbar / use full-screen if possible
- [ ] Prepare screen recording software (OBS, Loom, etc.)

**Show:**

- Feature cards (scroll slowly)
- "3 steps" section
- Click **"Get started free"** button

## Scene 2: Sign-up (0:20 – 0:35)

**Narration:**

## Recording Tips

- Use a **2-minute version** for the Lemon Squeezy listing (skip scenes 6–7 if needed)
- Record **without narration first**, then add voiceover in editing
- Alternatively, add **on-screen text captions** instead of narration
- Keep mouse movements **slow and deliberate**
- Pause 1–2 seconds after each key action before moving on
- Export as **MP4 (H.264)**, max 100MB for most platforms
